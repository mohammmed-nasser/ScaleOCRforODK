# بناء ملف APK عبر GitHub Actions (بدون Android Studio)

1. افتح GitHub وأنشئ مستودعاً جديداً (New repository)، مثلاً باسم `ScaleOCRforODK`.
2. اجعله Private إذا كان المشروع سيُستخدم داخلياً، ثم أنشئ المستودع.
3. من صفحة المستودع اختر Add file ثم Upload files.
4. فك ضغط ملف المشروع على الكمبيوتر، ثم ارفع **محتويات مجلد `ScaleOCRforODK`** إلى جذر المستودع، بما فيها المجلد المخفي `.github` وملف `.github/workflows/build-apk.yml`.
   - تأكد أن `app`, `build.gradle.kts`, `settings.gradle.kts` و`.github` ظاهرة مباشرة في جذر المستودع، وليس داخل مجلد فرعي إضافي.
5. اضغط Commit changes.
6. افتح تبويب Actions. عند أول تشغيل قد يطلب GitHub تفعيل Actions للمستودع؛ وافق.
7. افتح سير العمل `Build Scale OCR APK`. إذا لم يبدأ تلقائياً، اضغط Run workflow ثم Run workflow.
8. انتظر حتى تنتهي المهمة بعلامة خضراء. افتح نتيجة التشغيل، وانزل إلى Artifacts، ثم نزّل `scale-ocr-debug-apk`.
9. فك ضغط الملف الذي نزلته؛ ستجد `app-debug.apk`. انقله إلى Samsung S22 وافتحه لتثبيته. قد يطلب Android السماح بالتثبيت من هذا المصدر؛ لا تسمح إلا إذا كنت أنت من بنيت الملف من مستودعك وتثق بمحتوياته.

## ملاحظات مهمة
- هذا ينتج **Debug APK للتجربة** وليس إصداراً منشوراً في Google Play أو APK موقعاً بمفتاح إصدار دائم.
- لا ترفع مفاتيح توقيع أو كلمات مرور إلى المستودع.
- صلاحية ملف Artifact الافتراضية هنا 14 يوماً؛ نزّله واحتفظ به محلياً.
- إذا فشل البناء، افتح المهمة الفاشلة في Actions وانسخ آخر 30–50 سطراً من سجل الخطأ وأرسلها للمساعدة في إصلاحه.
- نجاح البناء لا يثبت وحده أن كل أنواع أجهزة الميزان أو إصدارات ODK تعمل؛ اختبره أولاً على هاتف تجريبي وميزانك الفعلي.
